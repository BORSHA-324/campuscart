# CampusCart: Student Second-Hand Marketplace

CampusCart is an AI-powered web marketplace where students can buy and sell second-hand educational materials such as textbooks, calculators, and electronics.

## Technology Stack
- PHP 8 (Object-Oriented Programming) with PDO
- MySQL
- HTML5, CSS3, JavaScript, Bootstrap 5
- Google Gemini API (AI features)

## Status
Project is under development.
